## Problem

The active multi-plan drifted away from the reason it was created. A DRAFT implementation proposal was promoted into mandatory architecture; validation concerns became production responsibilities; broad consumer inventories became fixed denominators; and later correction ledgers repeated the entire implementation campaign instead of governing the document repair.

That drift makes the plan unsafe in two directions:

- it can force work that has no demonstrated relationship to the five graph defects;
- it can still miss a real affected owner discovered later because the plan substituted a historical list for current source and impact evidence.

The correction must therefore cover the whole active authority in one closed matrix: one contract, one roadmap, seven four-file child sets, and this four-file correction set.
